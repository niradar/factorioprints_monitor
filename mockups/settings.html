Set up automatic daily snapshots (Windows) →
Run once in a terminal to scan daily at 08:00, even when the app is closed - it writes straight to the database.
Command Prompt
schtasks /Create /SC DAILY /ST 08:00 /TN "FactorioPrintsSnapshot" ^
  /TR "\"C:\projects\factorioprints_monitor\run_snapshot.bat\" https://factorioprints.com/user/I6YX1Ar1cWUwhbQgMcW4nyZkDs52"
Then in Task Scheduler enable “Run as soon as possible after a missed start” so it still runs if the PC was off. Edit /ST 08:00 to change the time.
